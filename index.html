How Cross-Venue Binary Arbitrage Pricing Works

Because mutually exclusive YES + NO contracts on identical settlement rules pay $1.00 at resolution, a hedged pair locks in 1.00 - (P_YES + P_NO + fees + slippage) whenever positive.

RISK ENGINEERING & FAQ

Execution Risks & Methodology

No. All results shown in this repository are from a deterministic 60-day simulated L2 paper replay starting with $1,000.00 virtual capital. Real cross-venue trading introduces non-atomic leg execution risk (one venue fills while the other moves), oracle/settlement rule disputes, withdrawal/gas latency, and capital lockup opportunity cost.

src/matcher.py uses Synpath's rule comparison audit (same, insufficient, not_same) plus a MAX_DISAGREEMENT = 0.50 midpoint guard. In our replay universe, the TikTok enforcement pair is flagged not_same and explicitly skipped before any capital is allocated.

Kalshi uses synpath.FeeSchedule quadratic pricing: ceil(0.07 × C × P × (1 - P) × 100) / 100, rounding up to the nearest cent per order. Standard Polymarket CTF markets use 0.0% taker fees (configurable via quadratic_theta). Both entry and exit fees are deducted before checking the 2.0¢ minimum edge threshold.

server.py runs cleanly offline in Simulated L2 Mode, streaming synthetic order-book updates over WebSocket /ws/stream and serving the deterministic $1,000.00 paper replay ledger. Optionally, clicking Live Poly API queries Polymarket's public Gamma API directly.
